# Ably.Ssh

## Регламент работы с репозиторием

Этот проект ведётся по строгому циклу. Любая содержательная работа в репозитории выполняется только по шагам ниже.

1. Перейти в ветку `main` и убедиться, что работа ведётся именно в ней.
2. Перед любым содержательным действием обязательно синхронизироваться с удалённым репозиторием:
   - `git fetch origin`
   - `git pull --ff-only origin main`
3. Проверить состояние репозитория (`git status`), убедиться, что локальная копия актуальна и понятна.
4. Выполнить запрошенные изменения.
5. Снова проверить изменения (`git status`, при необходимости `git diff`).
6. Зафиксировать результат:
   - `git add ...`
   - `git commit -m "<сообщение на русском языке>"`
7. Сразу отправить изменения в удалённый репозиторий:
   - `git push origin main`

## Обязательный принцип

Полный цикл работы считается завершённым только тогда, когда изменения уже отправлены на сервер (в `origin/main`).
Если изменения не запушены, работа не считается завершённой.
